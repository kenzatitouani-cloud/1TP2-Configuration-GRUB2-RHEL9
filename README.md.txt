# TP2 – Configuration de GRUB2 sous RHEL 9

**Étudiante :** Kenza Titouani  
**Filière :** 4IIR  
**Année universitaire :** 2026–2027  
**Environnement :** Red Hat Enterprise Linux 9.6 – VMware

## Présentation

Ce TP porte sur la configuration du gestionnaire de démarrage GRUB2 sous Red Hat Enterprise Linux 9.

## Objectifs

- Comprendre le rôle de GRUB2 dans le démarrage de Linux.
- Identifier les fichiers et répertoires de configuration.
- Examiner les entrées de démarrage et les noyaux installés.
- Modifier les paramètres de GRUB2.
- Générer et vérifier la configuration GRUB2.
- Découvrir la récupération du mot de passe root.
- Découvrir la protection de GRUB2 par mot de passe.

## Environnement utilisé

- Système : Red Hat Enterprise Linux 9.6
- Virtualisation : VMware
- Terminal : Bash
- Éditeur : nano

## Organisation du dépôt

- `commandes.md` : commandes utilisées et leurs explications.
- `captures/` : captures d'écran des manipulations.
- `rapport/` : compte rendu du TP au format PDF.

## Conclusion

Ce TP permet de comprendre le fonctionnement de GRUB2 et son importance dans le processus de démarrage et l'administration d'un système Linux.
